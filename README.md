# Лабиринт сокровищ

Консольная текстовая игра на Python: вы исследуете лабиринт, собираете предметы,
решаете загадки, избегаете ловушек и пытаетесь добраться до сокровища.

## Установка

```bash
git clone https://github.com/Ctyzzz/project1_Yakushev_Arseny_M25-555.git
cd project1_Yakushev_Arseny_M25-555

# через poetry
poetry install

# или через Makefile
make install
